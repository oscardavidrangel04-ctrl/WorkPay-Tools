Report a calculator issue, broken page or correction to WorkPay Tools.

Reviewed August 27, 2026

To report an issue, include the page URL, non-sensitive inputs used, the result shown and what you expected. Do not send Social Security numbers, payroll account numbers or other sensitive personal information.

What to include in a correction

For the fastest review, include the calculator name, the inputs you used, the result you expected, the result you received and—when the issue involves a rule—the primary source you believe should be checked.

What we review

Feedback can cover formula errors, unclear wording, broken links, accessibility problems, outdated government references or a scenario that the calculator explains poorly.

How to report a calculator issue

Start with the exact page URL and describe the steps that produced the result. Include the non-sensitive values you entered, the result shown and the result you expected. If the question involves a wage rule or government reference, include the official source you think should be reviewed. Clear examples make it easier to reproduce a problem and check the formula.

Corrections and source updates

WorkPay Tools reviews reports about formula errors, outdated source links, unclear explanations, accessibility barriers and broken navigation. A correction may lead to a formula review, wording change, source update or technical fix. We try to keep the calculation itself separate from legal or tax assumptions so a correction can be evaluated against the right source.

Privacy when sending feedback

Do not include Social Security numbers, bank details, payroll account credentials, passwords or other sensitive identifiers. Most calculator issues can be reproduced with sample values instead of real personal records. If you are reporting a display problem, describe the browser or device only when it helps explain the issue.

Before reporting a difference

Remember that WorkPay Tools provides planning estimates. Actual payroll can differ because of taxes, deductions, benefits, bonuses, rounding, employer policies or rules that the calculator does not model. If the arithmetic itself looks wrong, send the example so it can be checked.
